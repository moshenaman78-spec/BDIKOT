# Shaked Test Reports — אפליקציה חדשה (React + TypeScript + Vite)

מערכת דוחות בדיקה של שקד הנדסת חשמל. האפליקציה הקיימת (v2.2.552) נשארת ב-`/`; החדשה נבנית כאן ומוגשת ב-`/app/`.

```bash
npm install
```
```bash
npm run dev
```
```bash
npm test
```
